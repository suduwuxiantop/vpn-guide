# Hysteria2 小白搭建教程：从买服务器到能用，照着做就行

这篇是给完全没搭过服务器的人写的。前面写过一篇 Hysteria2 的技术向教程，这篇不讲原理，只讲"手指头怎么动"——每一步做什么、为什么做、做完应该看到什么样的结果、看到别的结果说明哪里错了。跟着一步步来，不需要你懂任何网络知识。

## 开始之前，你需要准备好这4样东西

1. **一台海外服务器（VPS）**——推荐先买最便宜的套餐练手，1核1GB内存、系统选 **Ubuntu 22.04** 就够用。买完你会拿到三样信息：一个IP地址（一串数字，比如 `123.45.67.89`）、一个用户名（通常是 `root`）、一个密码。这三样东西必须留好，后面全程都要用。

2. **一个能连SSH的软件**——Windows电脑用 **Xshell** 或者系统自带的"终端"（Windows Terminal）都行；Mac电脑直接用自带的"终端"App就行，不用额外装东西。

3. **一个域名**（可选，但强烈建议有）——不到10块钱能买一个，随便找个域名注册商买一个就行。如果暂时没有域名也能搭，本教程会在对应步骤说明两种情况怎么操作。

4. **手机上装好Clash Verge或者其他客户端**——搭完服务器之后要用它连接，先不装也没关系，搭到最后一步再装。

准备好这些，往下开始操作。

---

## 第一步：登录你的服务器

打开你的SSH软件（Xshell/终端/Windows Terminal都可以），输入下面这行命令，把里面的IP换成你自己服务器的IP：

```bash
ssh root@你的服务器IP
```

比如你的IP是 `123.45.67.89`，就输入：

```bash
ssh root@123.45.67.89
```

按回车。第一次连接会弹出一行英文问你要不要继续连接，输入 `yes` 再按回车。

接着它会让你输入密码——**注意，输入密码的时候屏幕上不会显示任何字符，也不会显示星号，这是正常的，不是电脑坏了**，把密码打完直接按回车就行。

**你应该看到什么**：屏幕最前面变成类似 `root@一串字符:~#` 这样的样子，说明你已经成功登录到服务器里面了。接下来所有命令都是在这个界面里输入的。

**如果卡在这一步**：多半是IP、用户名或密码输错了，回去邮箱里翻一下买服务器时商家发的信息，一个字符一个字符对照着输，注意有没有多余的空格。

---

## 第二步：一键安装 Hysteria2

登录进服务器之后，把下面这一整行复制粘贴进去，然后按回车：

```bash
bash <(curl -fsSL https://get.hy2.sh/)
```

这行命令的意思是：从Hysteria2官方网站下载一个安装脚本并自动执行，会自动帮你把程序装好。

**你应该看到什么**：屏幕会滚动出现一堆安装过程的文字，最后停在类似"安装成功"的提示上，光标恢复到 `root@...#` 这一行，说明装好了。这个过程一般十几秒到一分钟。

**如果卡在这一步**：如果提示"command not found"（找不到命令），说明是极少数系统没有预装 `curl` 这个小工具，先输入 `apt update && apt install -y curl` 装上，装完再重新执行上面那一行。

---

## 第三步：准备一张"身份证"——申请证书

Hysteria2 必须要有一张真实的HTTPS证书才能正常工作（这个证书就像一张身份证，证明你的服务器身份是真实的，客户端连接的时候会验证这个）。这里分两种情况：

### 情况A：你有域名（推荐，跟着这个走）

**3.1 先把域名解析到你的服务器**

登录你买域名的那个网站的管理后台，找到"域名解析"或者"DNS解析"这个功能，添加一条解析记录：

- 记录类型选 `A`
- 主机记录填 `@`（表示直接用这个域名，不加前缀）或者你想要的前缀比如 `hy2`
- 记录值填你服务器的IP地址
- 保存

解析生效一般需要几分钟到半小时。你可以在电脑上打开命令行/终端，输入 `ping 你的域名`（比如 `ping hy2.yourdomain.com`）来检查，如果返回的IP地址跟你服务器IP一样，说明解析成功了。

**3.2 申请免费证书**

回到刚才登录服务器的那个SSH窗口，依次输入下面几行命令（一行一行输，每输完一行按一次回车，等它执行完再输下一行）：

```bash
curl https://get.acme.sh | sh -s email=你的邮箱地址
```

（把"你的邮箱地址"换成你自己真实能收邮件的邮箱，随便一个常用邮箱都行）

```bash
source ~/.bashrc
```

```bash
~/.acme.sh/acme.sh --issue -d 你的域名 --standalone
```

（把"你的域名"换成你解析好的那个域名，比如 `hy2.yourdomain.com`）

**你应该看到什么**：最后出现类似 "Cert success" 的绿色提示，说明证书申请成功了。

**如果卡在这一步**：最常见的原因是域名还没解析生效（回去检查第3.1步），或者80端口被占用（一般全新的服务器不会有这个问题）。

**3.3 把证书放到指定位置**

```bash
mkdir -p /etc/hysteria
~/.acme.sh/acme.sh --install-cert -d 你的域名 \
  --key-file /etc/hysteria/private.key \
  --fullchain-file /etc/hysteria/cert.pem
```

同样，把"你的域名"换成你自己的域名。这一步执行完不会有太多提示，正常情况没有报错就是成功了。

### 情况B：你暂时没有域名

Hysteria2 支持用一种"伪装证书"的方式跑起来（自签名证书 + 一个假装是别的网站的样子）。这种方式配置起来更简单，但安全性和稳定性都不如真实域名+真实证书，只建议临时应急使用。如果你打算长期用，还是强烈建议回去买个域名，几块钱一年，没有任何理由跳过这一步。

如果确实想先跑起来试试，可以先跳到第四步，配置文件里把域名相关的部分换成自动生成自签证书的写法（评论区/客服可以单独要这份配置模板）。

---

## 第四步：写配置文件，告诉Hysteria2怎么运行

输入下面这行命令，打开一个文本编辑器：

```bash
nano /etc/hysteria/config.yaml
```

**这是什么**：`nano` 是服务器里自带的一个记事本工具，跟你电脑上的记事本功能类似。执行完这行，屏幕会变成一个空白（或者已有内容）的编辑界面。

把下面这段内容**整段复制**，然后粘贴进这个编辑界面里（在大部分终端软件里，直接右键点击就是粘贴，或者用键盘快捷键Ctrl+Shift+V）：

```yaml
listen: :443

tls:
  cert: /etc/hysteria/cert.pem
  key: /etc/hysteria/private.key

auth:
  type: password
  password: 设置一个你自己的高强度密码

masquerade:
  type: proxy
  proxy:
    url: https://www.bing.com
    rewriteHost: true
```

**粘贴完记得做两件事**：

1. 把 `设置一个你自己的高强度密码` 这一行换成你自己想用的密码——建议是字母+数字混合的一串字符，比如 `Xk9mP2vQ7Lw3`，越随机越好，这个密码以后连接的时候要用
2. 保存并退出：按键盘上的 `Ctrl` + `X`，然后它会问你要不要保存，按 `Y`，再按一次回车确认文件名

**你应该看到什么**：退出编辑器后回到 `root@...#` 界面，说明保存成功了。

---

## 第五步：启动服务

依次输入下面几行命令：

```bash
systemctl enable hysteria-server
systemctl start hysteria-server
systemctl status hysteria-server
```

第三行执行完，屏幕上应该会显示一段绿色的 `active (running)` 字样，说明服务已经正常启动并且在运行中。

**如果显示的是红色的 `failed` 或者 `inactive`**：大概率是第四步配置文件里的证书路径写错了，或者密码那一行格式不对（比如中文引号、多余空格）。可以输入下面这行命令查看具体报错原因：

```bash
journalctl -u hysteria-server -n 50 --no-pager
```

把报错内容发给能帮你看的人（或者截图问客服），一般都是配置文件里的小错别字。

看到 `active (running)` 之后，按键盘上的 `Q` 键退出状态查看界面。

---

## 第六步：给端口开门（防火墙放行）

服务器软件本身跑起来了，但还需要"开门"让外面的流量能进来。输入：

```bash
ufw allow 443/udp
ufw allow 443/tcp
```

**特别重要的一步**：如果你的服务器是从阿里云、腾讯云、Vultr、DigitalOcean这类平台买的，光在服务器里面执行上面这两行还不够，还需要登录你买服务器那个平台的**网页控制台**，找到"安全组"或者"防火墙规则"这个设置页面，手动添加一条规则，把 443 端口（TCP和UDP都要）放行。这一步是最多新手漏掉的地方——服务器里配置都对，但云平台的控制台没放行，照样连不上。

---

## 第七步：在手机/电脑上连接

现在服务器这边已经全部搞定了，最后一步是让你的设备连上去。

**电脑上用Clash Verge**：

打开Clash Verge，找到"配置"或者"订阅"里的"添加"，选择手动添加一个新节点，类型选 `hysteria2`，然后依次填：

- 服务器地址：你的域名（如果是情况A）或者服务器IP（如果是情况B）
- 端口：443
- 密码：就是你在第四步配置文件里设置的那个密码
- SNI：填你的域名

填完保存，在节点列表里选中它，右上角点"测试延迟"，如果显示出一个数字（比如 120ms），说明连接成功了。

**手机上用小火箭（Shadowrocket，iOS）**：

打开App，右上角点加号，类型选 Hysteria2，同样填服务器地址、端口443、密码、SNI（域名），保存后点击连接，顶部状态栏出现小飞机图标就是连上了。

**怎么确认真的能用**：打开浏览器随便搜一个平时打不开的网站，能正常打开就说明整套流程都跑通了。

---

## 全流程检查清单

如果哪一步卡住了，从头对照这张清单排查：

- [ ] 服务器能SSH登录进去
- [ ] `bash <(curl -fsSL https://get.hy2.sh/)` 执行完没有报错
- [ ] 域名已经解析到服务器IP（`ping 域名` 能看到正确IP）
- [ ] 证书申请成功，看到过 "Cert success" 字样
- [ ] 配置文件里的密码和证书路径都写对了，没有多余空格或错别字
- [ ] `systemctl status hysteria-server` 显示 `active (running)`
- [ ] 443端口在服务器里放行了（`ufw`）
- [ ] 443端口在云平台的安全组/防火墙控制台里也放行了
- [ ] 客户端填的服务器地址、端口、密码、SNI跟服务端配置完全一致

九成的问题，对着这张清单从上到下走一遍都能自己找到。

---

如果照着做完还是卡在某一步，把卡住那一步的具体报错信息截图留下来，能更快定位是哪里的问题。
