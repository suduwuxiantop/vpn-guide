# v2rayN 新手订阅教程：从下载到导入订阅、选节点、开代理，照着做就行（2026）

v2rayN 是 Windows 上最老牌的代理客户端之一，界面简单、占用低，很多机场的教程都会推荐它。但新手第一次打开往往一头雾水：下载哪个压缩包？订阅链接填在哪？节点列表出来了为什么还是上不了网？

这篇是纯操作向的教程，不讲原理，每一步告诉你点哪里、应该看到什么、看到别的结果该怎么办。

## 本文要点

- **下载**：只从 GitHub 官方仓库 `2dust/v2rayN` 的 Releases 页面下载，选 Windows 64 位、带 `SelfContained` 字样的压缩包，免装 .NET 运行库。
- **解压位置**：解压到一个**路径里没有中文和空格**的文件夹，比如 `D:\v2rayN`。
- **导入订阅**：订阅分组 → 订阅分组设置 → 添加 → 粘贴订阅链接 → 更新订阅。
- **订阅格式**：v2rayN 用的是"通用订阅 / V2Ray 订阅"链接，**不要填 Clash 专用订阅**。
- **能上网的关键两步**：选中一个节点设为活动节点，再把底部的"系统代理"设成"自动配置系统代理"。
- **新协议**：Hysteria2、VLESS+Reality 等新协议需要较新版本的 v2rayN 和内核，老版本请先更新。

---

## 第一步：下载 v2rayN

1. 浏览器打开 v2rayN 的 GitHub 官方发布页：

   ```
   https://github.com/2dust/v2rayN/releases
   ```

2. 找到最上面标着 **Latest** 的最新正式版，展开下面的 **Assets** 文件列表。
3. 普通 Windows 电脑下载文件名里带 **`windows-64`** 和 **`SelfContained`** 的 zip 压缩包。骁龙处理器的 ARM 笔记本选带 `arm64` 的。

**为什么选 SelfContained**：v2rayN 基于 .NET 开发，`SelfContained` 版本已经自带运行库，解压就能用；不带这个字样的版本需要你另外安装对应版本的 .NET Desktop Runtime，不然双击会提示缺少组件。

> ⚠️ 不要从"v2rayN 中文版""汉化版"之类的下载站下载，官方版本本身就是中文界面。

**如果 GitHub 打不开**：GitHub 在国内经常打不开或很慢，可以先参考下方的《GitHub 国内访问修复》，或者让机场客服直接提供官方安装包。

---

## 第二步：解压并打开

1. 在 D 盘（或其他盘）新建一个文件夹，比如 `D:\v2rayN`。**路径里不要有中文、空格**，也不要放在桌面或"下载"文件夹里。
2. 把下载的压缩包解压到这个文件夹。
3. 双击里面的 **`v2rayN.exe`**。

**你应该看到什么**：一个窗口，上面是空的服务器列表，下面是日志区域；同时任务栏右下角出现一个 v2rayN 的小图标。

**如果打不开**：

- 提示缺少 .NET → 你下载的不是 SelfContained 版，重新下载；
- 被杀毒软件删除或拦截 → 代理软件经常被误报，把 v2rayN 文件夹加入杀毒软件白名单；
- Windows 提示"已保护你的电脑" → 点"更多信息" → "仍要运行"。

---

## 第三步：导入订阅

### 3.1 复制订阅链接

登录你的机场后台，找到"订阅链接"或"一键订阅"。机场一般会提供多种格式，**选择"通用订阅""V2Ray 订阅"或"v2rayN"那一项**，复制链接。

> 不要选"Clash 订阅"。Clash 订阅返回的是 YAML 配置文件，v2rayN 无法正确识别，导入后会出现节点为空或乱码。

### 3.2 添加订阅

1. 点击菜单栏的 **订阅分组 → 订阅分组设置**。
2. 在弹出的窗口里点 **添加**。
3. **备注** 随便填，比如机场名字；**可选地址（url）** 粘贴刚才复制的订阅链接。
4. 点 **确定**，关闭订阅设置窗口。

### 3.3 更新订阅

点击菜单栏的 **订阅分组 → 更新全部订阅（不通过代理）**。

**你应该看到什么**：底部日志区域显示更新成功，服务器列表里出现一长串节点。

**如果没有节点出现**：

- 检查订阅链接是否完整复制，有没有多余空格；
- 确认选的是通用订阅而不是 Clash 订阅；
- 检查机场套餐是否到期、流量是否用完；
- 如果机场的订阅地址本身在国内被屏蔽，可以先手动导入一个节点连上后，再用"更新全部订阅（通过代理）"。

---

## 第四步：测速并选择节点

1. 在服务器列表里按 `Ctrl + A` 全选，右键选择 **测试服务器真连接延迟**（快捷键 `Ctrl + R`）。
2. 等几秒钟，每个节点后面会显示延迟数字（毫秒），显示 `-1` 或超时的节点表示连不上。
3. 选一个延迟合适的节点，**双击它**（或者选中后按回车），把它设为活动节点。

**你应该看到什么**：被选中的节点前面会有标记，窗口底部和托盘图标的提示里会显示当前节点名称。

> 延迟最低不一定最好用。延迟数字只代表"握手快不快"，实际看视频、下载是否流畅还和带宽、线路有关，详见下方《为什么测速显示的延迟数字，跟实际用起来的感觉不一样》。

---

## 第五步：开启系统代理

这一步是最多新手漏掉的：**选好节点不等于浏览器已经在用代理了。**

在窗口底部（或右键托盘图标）找到 **系统代理**，选择 **自动配置系统代理**。

**你应该看到什么**：托盘图标颜色发生变化；打开浏览器访问 `google.com` 能正常打开。

系统代理的几个选项：

| 选项 | 含义 |
|---|---|
| 清除系统代理 | 关闭代理，浏览器直连 |
| 自动配置系统代理 | 把 Windows 系统代理指向 v2rayN，**日常用这个** |
| 不改变系统代理 | v2rayN 运行，但不修改系统设置（适合手动给软件配代理的人） |

---

## 第六步：设置路由，国内网站不绕路

默认情况下可能所有网站都走代理，访问淘宝、B 站反而变慢，还白白消耗流量。

在窗口底部找到 **路由**，选择 **绕过大陆**（不同版本可能叫"绕过大陆(Whitelist)"之类）。这样国内网站直连，国外网站走代理。

---

## 第七步（可选）：开启 TUN 模式

系统代理只对会读取系统代理设置的软件生效，比如浏览器。像 Claude Code、Codex、游戏、部分桌面软件，不读系统代理，就需要开启 TUN 模式接管全部流量。

在窗口底部找到 **启用 Tun** 开关并打开。TUN 模式需要管理员权限，如果提示权限不足，退出 v2rayN 后**右键 `v2rayN.exe` → 以管理员身份运行**，再打开开关。

---

## 第八步：设置开机自启和更新

- **开机自启**：设置 → 参数设置 → 勾选"开机自动启动"。
- **更新 v2rayN 和内核**：菜单 → 检查更新，可以分别更新 v2rayN 本身和 Xray、sing-box 等内核。**如果你的机场节点有 Hysteria2、VLESS+Reality、AnyTLS 等新协议，一定要保持较新的版本**，老版本可能导入后显示正常但始终连不上。
- **定期更新订阅**：机场更换节点后，需要重新"更新全部订阅"才能拿到新节点。可以在订阅分组设置里设置自动更新间隔。

## 常见问题速查表

| 现象 | 最可能的原因 | 怎么解决 |
|---|---|---|
| 双击 v2rayN.exe 没反应或提示缺少组件 | 下载的不是 SelfContained 版 | 重新下载带 SelfContained 的压缩包 |
| 更新订阅后没有节点 | 订阅格式选错 / 链接不完整 / 套餐到期 | 换通用订阅链接；检查套餐状态 |
| 节点测速全部 -1 或超时 | 电脑时间不准、内核太旧、网络限制 | 校准系统时间；更新内核；参考《节点全部超时怎么办》 |
| 节点有延迟，但浏览器打不开网页 | 没开系统代理 | 底部系统代理选"自动配置系统代理" |
| 国外网站能开，国内网站变慢 | 路由设置成了全局 | 路由选"绕过大陆" |
| 浏览器能用，命令行 / 部分软件不能用 | 这些软件不读系统代理 | 开启 TUN 模式 |
| 关掉 v2rayN 后电脑上不了网 | 系统代理没被清除 | 重新打开 v2rayN 选"清除系统代理"后再退出 |
| 只有 Hysteria2 节点连不上 | 当前网络限制 UDP | 换 VLESS+Reality 或 AnyTLS 节点 |
