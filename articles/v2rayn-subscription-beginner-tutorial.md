# v2rayN 新手订阅教程：从下载到导入订阅、选节点、开代理，照着做就行（2026）

v2rayN 是 Windows 上最老牌的代理客户端之一，界面简单、占用低，很多机场的教程都会推荐它。但新手第一次打开往往一头雾水：下载哪个压缩包？订阅链接填在哪？节点列表出来了为什么还是上不了网？

这篇是纯操作向的教程，不讲原理，每一步告诉你点哪里、应该看到什么、看到别的结果该怎么办。

## 本文要点

- **下载**：只从 GitHub 官方仓库 `2dust/v2rayN` 的 Releases 页面下载，选 Windows 64 位、带 `SelfContained` 字样的压缩包，免装 .NET 运行库。
- **解压位置**：解压到一个**路径里没有中文和空格**的文件夹，比如 `D:\v2rayN`。
- **导入订阅**：订阅分组 → 订阅分组设置 → 添加 → 粘贴订阅链接 → 更新订阅。
- **订阅格式**：v2rayN 用的是"通用订阅 / V2Ray 订阅"链接，**不要填 Clash 专用订阅**。
- **能上网的关键两步**：选中一个节点设为活动节点，再把底部的"系统代理"设成"自动配置系统代理"。
- **新协议**：Hysteria2、VLESS+Reality 等新协议需要较新版本的 v2rayN 和内核，老版本请先更新。

## 常见问题速查表

| 现象 | 最可能的原因 | 怎么解决 |
|---|---|---|
| 双击 v2rayN.exe 没反应或提示缺少组件 | 下载的不是 SelfContained 版 | 重新下载带 SelfContained 的压缩包 |
| 更新订阅后没有节点 | 订阅格式选错 / 链接不完整 / 套餐到期 | 换通用订阅链接；检查套餐状态 |
| 节点测速全部 -1 或超时 | 电脑时间不准、内核太旧、网络限制 | 校准系统时间；更新内核；参考《节点全部超时怎么办》 |
| 节点有延迟，但浏览器打不开网页 | 没开系统代理 | 底部系统代理选"自动配置系统代理" |
| 国外网站能开，国内网站变慢 | 路由设置成了全局 | 路由选"绕过大陆" |
| 浏览器能用，命令行 / 部分软件不能用 | 这些软件不读系统代理 | 开启 TUN 模式 |
| 关掉 v2rayN 后电脑上不了网 | 系统代理没被清除 | 重新打开 v2rayN 选"清除系统代理"后再退出 |
| 只有 Hysteria2 节点连不上 | 当前网络限制 UDP | 换 VLESS+Reality 或 AnyTLS 节点 |
